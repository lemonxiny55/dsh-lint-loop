## Known limitations and downgrade behavior

- The current DSH `fs/observed` observation carries `present`/`absent`, but no
  stable old-path/new-path rename event. Delete/rename baseline migration is
  therefore not eager; the next lint/tool resolution and manager lifecycle
  bound stale state. This is documented in both READMEs.
- Direct edits outside the harness are not mutation-intent events and cannot
  receive a pre-edit baseline; the compatible tool path still works, but an
  unbaselined result is labeled conservatively.
- Headless agent-loop execution needs a DSH provider credential. The live boot
  and plugin registration smoke passed without making an external model call.
- npm registry metadata verified `dsh-lint-loop@0.4.0` as the `latest` dist-tag on 2026-09-27. npm does not expose reliable per-version download counts; package-level downloads are not attributed to this release.
- At the time this evidence was prepared, the GitHub remote still pointed to the 0.3.0 commit and had no `v0.4.0` tag. The source sync and GitHub Release are being completed separately.
